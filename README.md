# Level 0 — C# .NET, Database & SQL

> **Build your programming foundation, master relational databases and SQL, and learn Object-Oriented Programming using C#.**

---

## What You'll Learn

Level 0 is designed to build a strong foundation in **programming, databases, SQL, and Object-Oriented Programming using C#**.

Throughout this level, you will learn how to:

- Write C# programs from scratch
- Solve programming problems using C#
- Understand relational databases and database design
- Write SQL queries and work with relational data
- Apply Object-Oriented Programming principles
- Build complete C# applications

---

# Curriculum

# Projects

The projects in Level 0 are designed to help you apply the concepts learned throughout the curriculum in practical scenarios.

---

## 1. 🎓 Student Course Registration Database

**Sprint:** `Sprint 5 — Advanced SQL`

### Description

Build a complete relational database for managing a **Student Course Registration System**.

The system will manage:

| Entity | Description |
|---|---|
| 👨‍🎓 **Students** | Student information |
| 👨‍🏫 **Instructors** | Instructor information |
| 📚 **Courses** | Available courses |
| 🏢 **Departments** | Academic departments |
| 📝 **Enrollments** | Student course enrollments |
| 📊 **Grades** | Student grades |

### What You'll Apply

- Database Design
- ERD
- Database Normalization
- Database Keys & Constraints
- CRUD Operations
- SQL Queries
- Filtering & Aggregation
- Joins
- Subqueries
- CTEs
- Views
- Stored Procedures
- Transactions
- ACID Properties

### Expected Outcome

By completing this project, you should be able to design and implement a relational database and use SQL to manage and retrieve its data.

### Description

### What You'll Apply

- Classes & Objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstract Classes
- Interfaces
- Composition
- Collections
- Generics
- Exception Handling
- File-based Storage
- Optional SQL Database Integration

### Expected Outcome

By completing this project, you should be able to design and build a structured C# application using OOP principles and manage application data using collections and persistence.
