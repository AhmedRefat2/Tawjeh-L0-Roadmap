# Level 0 — C# .NET, OOP & Database SQL

> **6 Sprints · 12 Weeks · 2 Weeks / Sprint**  
> **Learning Order:** C# Basics → OOP → Database & SQL

---

## 🎯 Level 0

Level 0 builds the programming foundation required before moving into backend development.

### Tracks

1. **C# Basics**
2. **Object-Oriented Programming**
3. **Database & SQL**

### Learning Flow

```text
C# Syntax & Fundamentals
        ↓
Problem Solving
        ↓
OOP & Object Modeling
        ↓
Database Concepts & Design
        ↓
SQL & Data Retrieval
        ↓
Advanced SQL & Performance
```

---

# 🗺️ Sprint Overview

| Sprint | Weeks | Track | Focus |
|---|---:|---|---|
| 01 | 1–2 | C# Basics | .NET, C#, variables, data types, operators, conditions |
| 02 | 3–4 | C# Basics | Loops, arrays, methods, parameters, nullable, exceptions, algorithms |
| 03 | 5–6 | OOP | Paradigms, classes, objects, constructors, encapsulation, properties |
| 04 | 7–8 | OOP | Inheritance, polymorphism, binding, abstraction, interfaces, advanced OOP |
| 05 | 9–10 | Database & SQL | Database concepts, ERD, keys, normalization, DDL, DML, DQL |
| 06 | 11–12 | Database & SQL | Joins, functions, grouping, subqueries, CTE, indexes, transactions |

- Watch the assigned resource before practicing the topic.
- Write every solution yourself.
- Understand every submitted solution.
- Add the **exercise number, source, and link** above each exercise.

```text

├── README.md

```

For SQL:

```text
Exercise-001/
├── README.md
└── solution.sql
```

### Exercise README

```markdown
# Exercise 001

## Topic
...

## Source
...

## Problem
...

## Approach
...

## Solution
...

## Notes
...
```

### Required Comment in Source

```csharp
// Exercise 001
// Source: w3resource
// Link: <exercise-url>
```
